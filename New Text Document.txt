  ---
  🔧 Technical Configuration Prompt:

  Configure the LLM Council MCP server from: C:\DATA\llm-council-local\backend\mcp_server\server.py

  The server name is "llm-council" and it runs on stdio transport. Available tools:
  - council_query: requires "prompt" (string), optional "models" (array of strings), optional "chairman" (string)
  - council_list: no parameters required
  - council_availability: no parameters required

  The backend API runs on http://localhost:8000 and the MCP server will communicate with it.
